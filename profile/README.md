### Why we exist

Indie teams should spend time on the game — not on naming chaos, missing UI kits, or the same boilerplate every project.

**University of Games** ships reusable Unity products from real production experience: editor tools, complete tutorials, graphics and audio packs, and small utilities that remove friction.

### Products

Browse the full catalog on the [Unity Asset Store](https://assetstore.unity.com/publishers/25633). Technical docs live on GitBook:

- **[Complete Game Tutorials](https://university-of-games.gitbook.io/welcome/products/complete-game-tutorials)** — ship-ready Unity projects and learning packs
- **[Graphics Pack](https://university-of-games.gitbook.io/welcome/products/graphics-pack)** — 2D icons, card decks, Golf Pack starter kit
- **[Editor Tools](https://university-of-games.gitbook.io/welcome/products/editor-tools)** — workflow tools such as Assets Management Toolkit
- **[Utilities](https://university-of-games.gitbook.io/welcome/products/utilities)** — production utilities including Virtual Keyboard
- **[Unity Sound Packs](https://university-of-games.gitbook.io/welcome/products/unity-sound-packs)** — studio WAV packs for cards, toys, and more

[Documentation home →](https://university-of-games.gitbook.io/welcome/)

### Open source

Public samples and toolkits under [`@universityofgames`](https://github.com/universityofgames):

- [`unity-localization-toolkit`](https://github.com/universityofgames/unity-localization-toolkit) — localization plugin for Unity
- [`2d-starter-pack`](https://github.com/universityofgames/2d-starter-pack) — Coins, Stars, Potion, Diamonds cartoon icons
- [`2d-character-controller`](https://github.com/universityofgames/2d-character-controller) — complete 2D controller with camera
- [`2d-progress-bar-toolkit`](https://github.com/universityofgames/2d-progress-bar-toolkit) — 2D progress bar toolkit for UI
- [`how-to-use-NFTs-in-Unity`](https://github.com/universityofgames/how-to-use-NFTs-in-Unity) — NFT integration guide (ChainSafe)
