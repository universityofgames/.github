## Mission

We help indie teams **ship faster** with reusable Unity editor tools, complete game tutorials, graphics and audio packs, and small utilities that remove everyday friction.

Everything comes from real production work — naming chaos, missing UI kits, and repeated boilerplate should not be the game.

## What we ship

| Focus | Delivery |
| :--- | :--- |
| **Asset Store products** | Editor tools, complete tutorials, graphics, sounds, and utilities — documented on GitBook and sold on the [Unity Asset Store](https://assetstore.unity.com/publishers/25633). |
| **Technical documentation** | Package-level docs: folder layout, naming, prefabs, demos, and import notes on [GitBook](https://university-of-games.gitbook.io/welcome/). |
| **Education & writing** | Practical guides on [Medium](https://medium.com/university-of-games) — Unity, design, and shipping. |
| **Open source samples** | Controllers, toolkits, and starter assets under [`universityofgames`](https://github.com/universityofgames). |
